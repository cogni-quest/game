# Cogni Quest — игра

Обучающая игра для одного ребёнка: сначала математика, потом логика, память и
внимание. Игра вокруг — сегодня Kings Bounty, завтра что-то другое — нужна
только для мотивации.

Преемник `quest` (заморожен). Пока ничего не построено; начинать с
документов:

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — ядро, плагины задач, плагины
  игр, облако, переход со старой версии.
- [docs/CURRICULUM.md](docs/CURRICULUM.md) — граф навыков: что ребёнок учит и
  в каком порядке.
